# .github

Account-level defaults for [dhtfish988](https://github.com/dhtfish988)'s repositories.

GitHub uses the community health files in this repository for any repository of this
account that does not define its own: the contributing guide, the pull request
template and the issue form. Consult the target repository's README and security
policy, where provided, for its scope and reporting channel. Not every repository
has a security policy or private vulnerability reporting enabled.

There is no CODE_OF_CONDUCT file. These are single-maintainer repositories, and a
document promising enforcement I am not in a position to carry out would be noise.
